Princpais formatações

Negrito / Destaque

Nessa frase temos um termo em negrito usando a tag B

Nessa frase temos um termo em destaque usando a tag STRONG

Itálico

Nessa frase temos um termo em itálico usando a tag I

Nessa frase temos um termo em ênfase usando a tag EM

Texto Marcado

Podemos criar também um texto marcado usando a tag MARK.

Também podemos criar um texto marcado usando a tag MARK com style de CSS.

Texto Grande e Pequeno

Podemos criar um texto grande usando a tag BIG. Mas essa tag é obsoleta e não é recomendada para uso moderno.

Podemos criar um texto pequeno usando a tag SMALL.

Texto deletado

Podemos criar um texto deletado usando a tag DEL para mostrar que ele deve ser lido, mas não ser considerado parte do conteúdo.

Texto inserido

Podemos criar um texto inserido usando a tag INS para mostrar que ele deve ser lido e considerado parte do conteúdo, mas que foi adicionado posteriormente.

Texto Subscrito e Sobrescrito

Podemos criar um texto subscrito usando a tag SUB. Para usar, por exemplo, em fórmulas quimicas: H2O

Podemos criar um texto sobrescrito usando a tag SUP. Para usar, por exemplo, em fórmulas matemáticas: x2
